# 星宝预置知识储备设计

## 目标

星宝不能只像一个临时联网问答机器人。它应该像一个提前做过准备的伙伴：知道孩子最近喜欢什么，也知道今天有什么值得聊的内容。

第一版预置知识分三类：

- 兴趣主题：恐龙、天气、情绪表达等，可用于故事、科普和追问。
- 今日上下文：天气、城市、温度、儿童提醒。
- 特殊日子：父亲节、端午节、中秋节等，可用于主动祝福和儿童友好科普。

## 运行规则

1. 孩子问天气、今天是什么日子这类问题时，优先走本地快速回复。
2. 孩子问故事、科普、情绪表达时，把匹配到的知识卡注入 prompt，让 LLM 生成更有准备的回答。
3. 今日天气不在代码里写死，统一写入 `config/daily_context.json`，后续可以由天气接口、板卡启动脚本或人工演示配置更新。
4. 节日知识不直接替代 LLM，但可以给星宝提供稳定的祝福语和科普事实。
5. 所有内容必须适合学龄前儿童，避免恐怖、危险、成人化和评价式表达。

## 示例

天气：

```json
{
  "city": "杭州",
  "weather": {
    "condition": "多云",
    "temperature_range": "26到32度",
    "child_advice": "可以喝一小口水，出去玩要注意别晒太久。",
    "updated_at": "2026-07-02 08:00"
  }
}
```

节日：

```json
{
  "today_special_days": [
    {
      "name": "父亲节",
      "facts": ["父亲节是感谢爸爸和照顾我们的家人的日子。"],
      "child_hook": "记得对爸爸说一声节日快乐，也可以给他一个抱抱。"
    }
  ]
}
```

孩子问“今天天气怎么样”，星宝可以立刻回答：

```text
杭州今天天气多云，大约26到32度。可以喝一小口水，出去玩要注意别晒太久。
```

孩子问“端午是什么”，星宝可以回答：

```text
端午节是一个很有意义的日子。端午节常见习俗有吃粽子、赛龙舟、挂艾草。如果你吃粽子，可以观察一下粽叶是什么颜色、闻起来香不香。
```

## 后续扩展

- 增加年龄分层：3-4岁更短，5-6岁增加因果解释，7-8岁加入更多知识点。
- 增加兴趣追踪：如果孩子多次问恐龙，自动提高恐龙知识卡优先级。
- 增加演示模式：评委演示前一键切换“今天是父亲节/端午节”等上下文。
- 增加天气更新脚本：启动项目时写入 `daily_context.json`，语音链路只读取本地缓存。
