# 星宝硬件关系图生成提示词

请生成一张适合大学生科技竞赛答辩 PPT 的“星宝智能儿童早教陪伴桌硬件关系图”。整体采用简洁、专业、信息图式的扁平化设计，横向 16:9 构图，白色或浅灰背景，模块使用轻微圆角矩形与细阴影，连线横平竖直，避免交叉和装饰性元素。

画面中心放置深蓝色核心模块“SC171 V3 核心计算与交互调度平台”，副标题为“本地唤醒、VAD、多模态融合、游戏调度、安全策略”。

左侧为“感知输入层”，自上而下排列：

1. USB 麦克风：唤醒、语音、插话输入；
2. 触控输入：点击、拖拽、选择；
3. USB 摄像头：距离检测、视觉感知，标记为“扩展能力”。

右侧为“反馈输出层”，排列：

1. 22.5 英寸触控屏：星宝形象、游戏、提示；
2. 声卡、功放、扬声器：回复、提示音、鼓励语音。

上方为紫色“云端智能服务”，包含 ASR 语音识别、Qwen 大模型、TTS 语音合成，与 SC171 V3 使用双向箭头连接，标注“Wi-Fi/LAN，HTTPS/WebSocket”。

下方为“电源与结构层”，包括：

1. 电源适配与分配：向核心板、触控屏和音频设备供电；
2. 纸箱桌体与实体教具区：固定、承载、分区、走线。

连接关系必须准确：麦克风到核心板标注“USB 音频输入”；触控输入到核心板标注“触控数据回传”；摄像头到核心板使用绿色虚线并标注“USB 视频输入（扩展）”；核心板到触控屏标注“显示信号”；触控屏到核心板标注“触控控制”；核心板到扬声器标注“音频输出”。扬声器到麦克风增加红色虚线，标注“声学回声/串音”。纸箱桌体与各硬件使用灰色无箭头虚线，表示“固定/承载”。

颜色规范：输入感知使用青蓝色 `#24B7D3`，核心计算使用深蓝色 `#3456D1`，云端智能使用紫色 `#7C5CFC`，反馈输出使用橙色 `#FF9E45`，视觉扩展使用绿色 `#36B37E`，供电与风险使用红色 `#E85D75`，分区底色使用灰白色 `#F5F7FB`。

图中不要出现机械臂、舵机、PWM、GPIO、原始串口、底层控制参数或未经确认的电压值。不要使用渐变、3D 图标、复杂背景或卡通插画。保证中文清晰、字号统一、模块对齐，并在底部放置小型图例，说明当前数据连接、音频链路、扩展能力、供电关系、结构关系和干扰关系。
