## 本轮改动

- 新增触控色块盘：孩子可以点颜色，再点战线空格完成出块。
- 新增颜色选中态和战线空格呼吸态。
- 长按颜色可获得一句儿童可理解的效果说明。
- 牌位展示从“按玩家显示”调整为“按战线显示”：星光线展示放到星光线的牌，守护线展示放到守护线的牌。
- 已出牌显示归属标记：“你”或“星宝”。
- 色块盘位置上移，避免压住底部语音栏。

## 与目标图的主要差距

1. 目标图的触控/语音入口是“仪式化控制台”，当前色块盘仍然偏调试控件。屏幕已支持触控，后续要把色块盘升级为正式主控台，而不是边缘装饰层。
2. 目标图的光幕有多层光纱、粒子顺流和中心爆点，当前光线仍是普通 Canvas 曲线。
3. 目标图的卡牌是高质感牌背，当前卡牌能表达状态，但缺少资产级边框、角标和暗纹。
4. 目标图星宝头像更像一个完整角色，当前仍是 CSS 拼装形象。
5. 目标图的事件提示更克制，当前右侧牌局记录仍偏调试面板。

## 下一轮建议

P0：把玩法 V2 的连携反馈同步到网页

- 当前 Python 规则层已有连携，但网页原型还未同步。
- 下一轮应让网页也显示“勇气灵感”“守护修复”等短反馈。

P0：建立正式前端目录和资产 manifest

- 新建 `web/color-block/`。
- 保留当前 `web/color_block_game.html` 作为交互原型。
- 将下一阶段视觉重构放到新目录，避免原型越来越难维护。

P1：重做光幕层

- 引入 PixiJS 或同级 WebGL 2D 渲染。
- 先复刻目标图的金色/蓝色流动光幕，不急着全量重做 HUD。

P1：替换星宝为资产化角色

- 至少先做静态状态帧：聆听、思考、开心、安慰、指左、指右。

## 本轮结论

本轮主要提升“能玩”和“孩子不用键盘也能玩”，不是美术突破。它让交互方向更可靠，但距离目标图的高级感仍然需要下一阶段的资产化和 WebGL 光效。
