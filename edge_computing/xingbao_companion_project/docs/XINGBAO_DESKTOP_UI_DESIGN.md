# 星宝学习桌面主界面 UI 与交互设计

## 1. 设计定位

星宝学习桌面的主界面应当像一张真实的儿童学习桌，而不是平板应用启动器。

主界面的第一印象是：

- 孩子正在一张温暖、安全、低干扰的桌面前。
- 星宝是陪伴对象，也是主要互动入口。
- 工具、游戏、记录都被收纳在桌边，需要时再打开。
- 家长能看到设备可靠性、健康提示和必要设置，但这些信息不抢孩子注意力。

本设计以当前概念图为基准：顶部常驻状态栏，中间星宝桌宠，右侧「回忆本」抽屉，左下「小抽屉」，桌面背景包含台灯、书本、积木、画纸等学习桌物件。

## 2. 核心原则

### 2.1 不做应用启动器

主界面不直接展示大尺寸的「游戏」「百宝箱」「聊天」入口。

游戏和工具虽然重要，但它们不应在主屏幕中央吸引孩子注意力。它们应被收纳到桌面边缘，符合真实学习桌的物理隐喻。

### 2.2 星宝是主角，不是按钮

星宝桌宠承担：

- 语音唤醒后的视觉反馈。
- 点击后的主动语音互动。
- 拖动和陪伴状态。
- 学习、故事、护眼、情绪支持的引导。

主界面不需要额外放一个巨大的「开始聊天」按钮。孩子应通过「叫星宝」「点星宝」「看星宝状态」自然进入互动。

### 2.3 桌面边缘负责收纳

桌面区域按真实学习桌理解：

| 桌面区域 | UI 含义 |
| --- | --- |
| 顶部边缘 | 系统状态栏、健康提示、家长入口 |
| 中央桌面 | 星宝陪伴、语音互动、当前提示 |
| 左下桌角 | 小抽屉，收纳工具、游戏、收藏、护眼休息 |
| 右侧桌边 | 回忆本，承载聊天记录、故事记录、TTS 重播 |
| 背景物件 | 学习桌氛围，后续可扩展为低优先级热区 |

### 2.4 儿童低干扰

主界面默认只保留一个主要行动方向：和星宝互动。

其他功能通过轻量入口出现：

- 小抽屉：低调、可打开、可关闭。
- 回忆本：右侧书签式入口。
- 家长设置：右上角，需要验证。
- 游戏：只有在孩子主动打开小抽屉后才出现。

## 3. 总体布局

推荐按 16:9 横屏触控桌面设计。

```text
┌──────────────────────────────────────────────┐
│ 顶部状态栏 8%                                 │
│ 时间/日期/健康提示       星宝学习桌面       状态/家长 │
├──────────────────────────────────────────────┤
│                                              │
│              当前提示文案                     │
│          今天想和星宝聊什么？                  │
│                                              │
│                    星宝桌宠                   │
│                                              │
│ 小抽屉入口                              回忆本入口 │
└──────────────────────────────────────────────┘
```

### 3.1 区域比例

| 区域 | 建议占比 | 说明 |
| --- | --- | --- |
| 顶部状态栏 | 高度 8% | 常驻系统层，游戏全屏时隐藏 |
| 主互动区 | 高度 78%-82% | 星宝、提示文案、桌面视觉 |
| 左下小抽屉入口 | 宽 15%-18%，高 8%-10% | 固定在左下桌角 |
| 右侧回忆本入口 | 宽 5%-7%，高 26%-34% | 半露出书签/本子边 |
| 回忆本展开面板 | 宽 35%-40% | 从右侧滑出 |
| 小抽屉展开面板 | 宽 34%-42%，高 24%-32% | 从左下或底部滑出 |

### 3.2 默认视觉层级

视觉优先级从高到低：

1. 星宝桌宠。
2. 当前提示文案。
3. 顶部健康状态。
4. 小抽屉入口、回忆本入口。
5. 桌面背景物件。
6. 系统图标。

游戏和百宝箱不出现在默认主视觉里。

## 4. 顶部系统常驻状态栏

### 4.1 显示规则

| 场景 | 状态栏 |
| --- | --- |
| 主界面 | 显示 |
| 回忆本展开 | 显示 |
| 小抽屉展开 | 显示 |
| 百宝箱/组件库 | 显示 |
| 家长设置 | 显示 |
| 游戏选择页 | 可显示 |
| 游戏进行中全屏 | 隐藏 |
| 故事沉浸播放 | 可淡出隐藏 |
| 锁屏页 | 显示简化版 |

### 4.2 左侧信息

显示内容：

```text
08:30  5月20日  星期二  |  坐姿端正，眼睛离书本一尺远
```

健康提示不展示原始传感器数值，使用儿童和家长都能理解的自然语言。

可选文案：

- 坐姿端正，眼睛离书本一尺远
- 光线很好，适合阅读
- 光线有点暗，开亮一点更舒服
- 离屏幕有点近，我们坐远一点
- 该眨眨眼，看看远处啦

### 4.3 中间品牌区

显示：

```text
[星宝小 logo] 星宝学习桌面
```

中间品牌区不作为主操作入口。点击后可轻微反馈，但不进入复杂页面。

### 4.4 右侧系统区

右侧图标：

```text
网络  音量  电量  锁屏  家长设置
```

交互：

| 图标 | 点击结果 |
| --- | --- |
| 网络 | 弹出网络状态小面板，只显示当前连接、联网状态 |
| 音量 | 弹出音量滑条，可调节语音和系统音量 |
| 电量 | 弹出电量与充电状态 |
| 锁屏 | 需要长按或二次确认，避免误触 |
| 家长设置 | 进入家长验证页 |

家长设置必须验证，不允许儿童直接进入隐私、使用记录、模型配置或内容安全设置。

## 5. 主互动区

### 5.1 默认状态

默认显示：

```text
今天想和星宝聊什么？
```

星宝位于中下方，保持可爱、清晰、可点击、可拖动。

主互动区避免出现功能按钮堆叠。桌面背景的书本、台灯、画纸、积木主要作为氛围，第一版不建议全部做成可点击入口。

### 5.2 中央文案状态

中央提示文案根据系统状态切换：

| 状态 | 文案 |
| --- | --- |
| 待机 | 今天想和星宝聊什么？ |
| 首次使用 | 点点星宝，说句话吧 |
| 唤醒成功 | 我在呢 |
| 正在听 | 我在听呢，说给星宝听吧 |
| 录音结束 | 星宝听到了 |
| 思考中 | 星宝想一想... |
| TTS 播放中 | 星宝正在讲给你听 |
| 播放暂停 | 要继续听吗？ |
| 护眼提醒 | 我们一起看看远处吧 |
| 坐姿提醒 | 坐舒服一点，星宝陪你慢慢来 |
| 网络异常 | 网络有点慢，星宝再试一下 |
| 麦克风异常 | 星宝好像听不清，我们检查一下麦克风 |

文案应短、温和、儿童可理解。

## 6. 星宝桌宠

### 6.1 显示规则

| 场景 | 星宝桌宠 |
| --- | --- |
| 主界面 | 显示 |
| 回忆本展开 | 显示，自动避让到左侧或中下方 |
| 小抽屉展开 | 显示，避让抽屉区域 |
| 百宝箱/组件库 | 显示为缩小悬浮形态 |
| 家长设置 | 可隐藏或弱化 |
| 游戏选择页 | 可显示 |
| 游戏进行中 | 隐藏，由游戏内星宝接管 |
| 故事沉浸播放 | 可变成小头像或隐藏 |

### 6.2 基础交互

| 操作 | 结果 |
| --- | --- |
| 单击星宝 | 进入语音监听状态 |
| 双击星宝 | 快速打招呼或重复上一句 |
| 长按星宝 | 打开星宝快捷菜单 |
| 拖动星宝 | 改变位置，松手后轻微吸附到安全区域 |
| 说话中点击星宝 | 暂停/继续 TTS 播放 |
| 拖到屏幕边缘 | 缩成边缘小头像 |
| 点击边缘小头像 | 恢复完整星宝 |

### 6.3 快捷菜单

长按星宝弹出小型菜单：

```text
和星宝说话
讲个故事
休息一下
回到桌角
```

菜单应靠近星宝出现，最多 4 个选项，不遮挡顶部状态栏、小抽屉、回忆本。

### 6.4 状态表现

| 状态 | 视觉表现 | 高层状态名 |
| --- | --- | --- |
| 待机 | 轻微漂浮、眨眼 | `smile` |
| 听孩子说话 | 蓝色呼吸光、耳朵/星星轻动 | `listening` |
| 思考中 | 小星星环绕、轻微转动 | `thinking` |
| 正在说话 | 暖黄色声波、口型动效 | `speaking` |
| 鼓励 | 点头、星星闪光 | `encourage` |
| 护眼 | 温和橙色提示光 | `eye_rest` |
| 网络/麦克风异常 | 轻微困惑表情，不夸张 | `gentle_notice` |

只允许输出高层表现状态，不允许引入机械臂、舵机、PWM、GPIO、串口原始控制。

## 7. 右侧回忆本

### 7.1 默认入口

右侧边缘露出一个竖向本子/书签式入口：

```text
[书本图标]
回忆本
```

入口固定在右侧中部偏下。它应明显可点，但不抢主视觉。

### 7.2 展开规则

点击入口后，右侧滑出面板：

- 宽度：屏幕 35%-40%。
- 高度：顶部状态栏下方到屏幕底部。
- 样式：像一本打开的软皮本或纸页，不像聊天软件窗口。
- 背景：暖白、浅纸张纹理。

展开后：

- 星宝自动向左或中下方避让。
- 小抽屉保持可见但不展开。
- 点击面板外区域、右滑、点击关闭按钮均可收起。

### 7.3 内容结构

```text
回忆本

今天
- 星宝讲了《小月亮找朋友》  [播放] [收藏]
- 颜色问答：红色和黄色      [播放]
- 睡前小结                  [播放] [收藏]

收藏
- 我喜欢的故事
- 常听内容
```

### 7.4 记录卡片字段

每条记录包含：

| 字段 | 说明 |
| --- | --- |
| 标题 | 故事名、问答主题、互动摘要 |
| 时间 | 今天/昨天/具体时间 |
| 类型 | 故事、问答、游戏、情绪陪伴、学习小结 |
| 摘要 | 简短文字摘要 |
| 播放 | 重新 TTS 播放 |
| 收藏 | 加入收藏 |
| 继续 | 对故事类记录可继续讲 |

禁止在回忆本中保存敏感儿童信息，例如家庭住址、电话、学校、班级、精确位置、家长联系方式。

### 7.5 交互

| 操作 | 结果 |
| --- | --- |
| 点击记录卡片 | 展开文字摘要 |
| 点击播放 | 从该记录重新合成并播放 TTS |
| 点击收藏 | 加入收藏分组 |
| 点击继续讲 | 将该记录作为上下文，继续故事或话题 |
| 长按记录 | 家长模式下可删除或管理 |
| 向右滑动 | 收起回忆本 |

播放 TTS 时，星宝进入 `speaking` 状态。播放结束后回到 `smile` 或 `followup_waiting`。

## 8. 左下小抽屉

### 8.1 默认入口

左下角显示一个木质或软质桌面抽屉把手：

```text
[星星把手] 小抽屉
```

它是二级功能入口，不是主功能按钮。

### 8.2 展开规则

点击后从左下角或底部滑出抽屉面板：

```text
小抽屉

[百宝箱] [一起玩]
[收藏]   [护眼休息]
```

建议第一版只放 4 个入口。

抽屉尺寸：

- 宽度：屏幕 34%-42%。
- 高度：屏幕 24%-32%。
- 位置：左下区域，不覆盖星宝主要位置。

点击抽屉外区域、再次点击把手、向下滑动均可收起。

### 8.3 入口定义

| 入口 | 作用 | 备注 |
| --- | --- | --- |
| 百宝箱 | 打开组件库主界面 | 包含番茄钟、画板、识字卡等工具 |
| 一起玩 | 打开游戏选择页 | 不直接进入强刺激游戏 |
| 收藏 | 打开收藏内容 | 故事、常用工具、喜欢的活动 |
| 护眼休息 | 打开护眼休息引导 | 可与顶部健康状态联动 |

### 8.4 百宝箱打开后的规则

点击「百宝箱」：

- 进入组件库主界面。
- 顶部状态栏保留。
- 星宝桌宠缩小并靠边。
- 右侧回忆本仍可打开。
- 小抽屉自动收起。

百宝箱内部应继续保持低干扰、工具化，不做大量游戏化诱导。

### 8.5 一起玩打开后的规则

点击「一起玩」：

1. 进入游戏选择页。
2. 游戏选择页可保留顶部状态栏和星宝桌宠。
3. 点击具体游戏后进入游戏全屏模式。
4. 游戏进行中隐藏顶部状态栏、主界面星宝、右侧回忆本、小抽屉。
5. 游戏内由游戏自己的星宝形象接管陪伴角色。

## 9. 游戏全屏模式

### 9.1 显示规则

游戏进行中：

- 隐藏顶部状态栏。
- 隐藏主界面星宝桌宠。
- 隐藏回忆本入口。
- 隐藏小抽屉入口。
- 保留游戏内必要控件。

游戏内不得出现第二个独立浮动星宝。只有游戏场景内的星宝角色。

### 9.2 游戏内最小控件

游戏全屏只保留：

```text
暂停
回家
音量
护眼倒计时
```

这些控件应在角落，尺寸足够触控，但不遮挡游戏主体。

### 9.3 暂停菜单

点击「暂停」后显示：

```text
继续玩
重新开始
回到桌面
音量
休息一下
```

暂停时可显示简化版顶部状态信息，但不恢复完整桌面状态栏。

### 9.4 退出规则

点击「回家」或暂停菜单的「回到桌面」：

- 二次确认，避免误触。
- 回到主桌面。
- 主界面星宝重新出现。
- 回忆本和小抽屉恢复默认收起状态。

## 10. 健康与护眼交互

### 10.1 顶部健康提示

健康提示常驻在顶部左侧，但不使用压迫式警告。

点击健康提示后弹出小浮层：

```text
护眼小提醒
当前光线：适合阅读
坐姿：很好
距离：合适

[开始休息一下]
```

### 10.2 护眼休息页

从顶部健康提示或小抽屉「护眼休息」进入。

内容建议：

- 看远处 20 秒。
- 闭眼休息一下。
- 跟星宝做眨眼游戏。
- 轻柔背景，不刺激。

结束后返回主桌面。

## 11. 家长设置

### 11.1 入口

顶部右侧齿轮图标：

```text
家长设置
```

点击后进入验证，不直接展示设置。

### 11.2 验证方式

可选：

- 密码。
- 家长 App 扫码。
- 简单算术题。

验证通过后进入家长中心。

### 11.3 家长中心内容

第一版建议包含：

- 使用时长。
- 护眼提醒设置。
- 音量和网络。
- 内容安全设置。
- 回忆本管理。
- 非敏感偏好管理。

不得展示或保存敏感儿童信息。

## 12. 桌面物件热区规划

概念图中的桌面物件可以分阶段处理。

### 12.1 第一版

| 物件 | 处理 |
| --- | --- |
| 台灯 | 纯氛围，不点击 |
| 书本 | 纯氛围，可作为后续故事入口 |
| 积木 | 纯氛围，可作为后续桌面识别/形状游戏入口 |
| 画纸 | 纯氛围，可作为后续画板入口 |
| 植物/书架 | 纯装饰 |

### 12.2 后续扩展

如果要给物件加热区，应遵守：

- 热区不能超过 3 个。
- 热区不显示强提示，只有点击时轻反馈。
- 物件入口不能取代小抽屉。
- 新手阶段可以短暂显示「点点画纸，和星宝画一画」之类提示，熟悉后自动消失。

## 13. 页面状态机

```text
主桌面 idle
  ├─ 点击星宝 -> listening
  ├─ 唤醒词 -> listening
  ├─ 点击回忆本 -> memory_drawer_open
  ├─ 点击小抽屉 -> desk_drawer_open
  ├─ 点击健康提示 -> health_popover
  └─ 点击家长设置 -> parent_verify

listening
  ├─ 录音结束 -> thinking
  ├─ 取消 -> idle
  └─ 超时 -> idle

thinking
  ├─ TTS 开始 -> speaking
  └─ 错误 -> idle_with_notice

speaking
  ├─ 播放结束 -> followup_waiting
  ├─ 点击星宝 -> paused
  └─ 停止 -> idle

desk_drawer_open
  ├─ 百宝箱 -> toolbox_home
  ├─ 一起玩 -> game_picker
  ├─ 收藏 -> favorites
  ├─ 护眼休息 -> eye_rest
  └─ 收起 -> idle

memory_drawer_open
  ├─ 播放记录 -> speaking
  ├─ 继续讲 -> thinking
  ├─ 收藏 -> memory_drawer_open
  └─ 收起 -> idle

game_picker
  ├─ 开始游戏 -> game_fullscreen
  └─ 返回 -> idle

game_fullscreen
  ├─ 暂停 -> game_paused
  ├─ 回家确认 -> idle
  └─ 护眼提醒 -> game_eye_rest
```

## 14. 触控与可用性要求

| 项目 | 要求 |
| --- | --- |
| 最小触控区域 | 不小于 64px |
| 主要入口触控区域 | 80px 以上 |
| 右侧回忆本把手 | 宽度不小于 72px |
| 小抽屉把手 | 高度不小于 80px |
| 关闭/返回按钮 | 必须清晰，避免小图标难点 |
| 长按操作 | 不作为唯一入口 |
| 二次确认 | 锁屏、退出游戏、删除记录必须有 |
| 误触处理 | 面板外点击只收起，不触发危险操作 |

## 15. 安全与隐私约束

1. 不在主界面展示儿童敏感信息。
2. 不在回忆本保存家庭住址、电话、学校、班级、精确位置、家长联系方式。
3. 不提供机械臂、舵机、PWM、GPIO、串口原始控制入口。
4. 星宝和游戏只输出高层表现状态，例如 `smile`、`listening`、`thinking`、`speaking`、`encourage`、`eye_rest`。
5. 家长设置必须经过验证。
6. 游戏全屏不允许诱导长时间连续使用，应保留护眼倒计时或休息提醒。

## 18. 验收清单

用于判断主界面设计是否符合本文件：

- 主屏幕第一眼是否像学习桌，而不是 App 列表。
- 默认状态下是否没有醒目的游戏按钮。
- 星宝是否是最明显的互动对象。
- 小抽屉是否能自然承载百宝箱和游戏。
- 回忆本是否能承载聊天记录、故事记录和 TTS 重播。
- 游戏全屏时是否隐藏主界面星宝，避免两个星宝。
- 顶部栏是否表达系统可靠性和健康守护。
- 家长设置是否被验证保护。
- 健康提示是否温和，不吓孩子。
- 是否没有新增机械臂、舵机、串口、PWM、GPIO 等非主线能力。
- 是否没有保存或展示敏感儿童信息。
