# 摄像头识别画面中央预览设计

## 目标

当 Qwen 决定调用 `inspect_current_camera` 且成功抓取一帧后，触控 UI 立即显示该同一帧画面。画面使用圆角矩形居中显示，帮助用户知道星宝正在查看什么；本轮识别结果开始播报时立即隐藏。

## 范围与边界

- 仅作用于 `inspect_current_camera` 工具成功抓取的画面。
- 图像只在内存中以压缩 JPEG data URI 传递和解码，不写入项目目录、缓存或日志。
- 给 Qwen 的图像和 UI 显示的图像必须来自同一次抓帧，禁止 UI 重新抓帧。
- 抓帧、图文推理或 UI 解码失败时，图片不显示或立即清除；既有的澄清回复保持不变。

## 数据流

1. `capture_current_camera_frame()` 产生 `CameraSnapshot`，其中包含 JPEG data URI、宽度和高度。
2. LLM 客户端在将该快照附到图文请求前，发出 `camera_snapshot_ready` 事件，携带 data URI 与尺寸元数据；该事件不打印图像内容。
3. 中心服务将事件转换为一次 UI 指令，发送 `camera_snapshot` 负载给触控 UI。
4. `tools/board_phase1_ui.py` 在 UI 线程验证 data URI、解码为 Pygame surface，并交给桌面对象保存为瞬时覆盖层。
5. 桌面每帧在主形象之上、对话字幕之下绘制覆盖层。首个识别结果 TTS 片段入队时，中心服务发送清除命令，UI 立刻移除该覆盖层。

## UI 规则

- 底部工具状态字幕为“让我看一看”。
- 预览保持原始宽高比，最大宽度为屏幕宽度的 62%，最大高度为屏幕高度的 58%。
- 居中显示，使用深色半透明底板、细描边和圆角裁切；不遮挡底部字幕区域。
- 该覆盖层不改变 Wayland 全屏窗口、焦点或窗口几何。
- 图片清除不影响场景 GIF、对话字幕状态或其他 UI 状态。

## 错误处理与隐私

- 负载类型、data URI 前缀、大小和 JPEG 解码均须校验；异常仅记录简短原因，禁止记录 Base64 内容。
- 一次命令最多允许一张受尺寸上限保护的图像，防止 UI IPC 负载膨胀。
- 中心服务重启、会话结束或新一轮摄像头预览开始时，旧预览必须清除。

## 验证

- 单元测试确认同一 data URI 同时用于 Qwen 图文请求和 UI 事件。
- IPC 测试确认有效快照会在 UI 线程设置并可清除；无效或过大内容被拒绝且不破坏 UI。
- 桌面渲染测试确认预览位于主内容中央、保留宽高比且不覆盖字幕区域。
- 集成回归确认摄像头工具调用时字幕为“让我看一看”，首个结果 TTS 入队后预览被清除。
