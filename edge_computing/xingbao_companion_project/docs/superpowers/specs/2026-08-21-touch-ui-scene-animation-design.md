# 星宝触控 UI 场景动画设计

## 目标

让 Wayland 触控主界面的星宝形象能够播放 24 个场景 GIF，并由 KWS、每轮对话的 LLM 场景选择、天气、夜间待机和非对话视觉情绪安全地驱动。

## 资源

`~/files/scenes` 中的 `01_打招呼.gif` 到 `24_太空宇航员.gif` 将复制到项目受管目录。场景编号 `1` 到 `24` 与文件名前缀一一对应；编号 `0` 表示不切换场景，保持默认形象。触控 UI 必须在资源缺失、GIF 解码失败或编号无效时回退到现有静态星宝形象。

## 场景选择协议

每一个正常 LLM 对话回合的系统提示将包含 24 个编号、含义和一个严格输出约定。模型回复正文后必须另行给出机器可解析的场景字段，取值只能是 `0` 到 `24`：

```text
[[XINGBAO_SCENE:12]]
```

服务端从最终 LLM 文本中移除该标记，绝不把它发送到 TTS、字幕、会话记录或儿童可见界面。缺失、重复、越界或无法解析的标记视为 `0`。若用户本轮输入与上一有效对话输入相同，则忽略本轮新选择、复用上一场景编号。`0` 或失败时不主动改变当前默认形象。

场景目录会明确指示模型积极使用适合当前语义的场景。天气相关回合中，若天气结果或对话语义为下雨则优先 `19_雨天撑伞.gif`，下雪则优先 `20_堆雪人.gif`。

## 优先级与状态

UI 使用单一场景状态机，任何时刻只显示一个 GIF 或默认静态形象：

1. KWS 唤醒立即显示 `01_打招呼.gif`。
2. 从唤醒到会话结束期间，对话场景选择可覆盖此前的问候动画；每轮 LLM 解析到的有效非零编号切换对应 GIF。
3. 会话进行期间所有视觉情绪事件直接丢弃，包括语音、字幕和动画请求。
4. 非对话期间，视觉情绪事件：高兴显示 `02_开心跳跃.gif`；难过和生气显示 `03_比心.gif`。其既有提示语音/字幕维持现有非对话规则。
5. 本地时间 23:00 之后，在非对话且距最后一次唤醒超过 10 分钟时显示 `22_晚安睡觉.gif`。夜间唤醒仍立即显示 `01_打招呼.gif`；会话结束后的 10 分钟无新唤醒才重新进入晚安场景。
6. 无有效场景、场景播放完毕、资源失败或凌晨非夜间待机时，都恢复现有默认星宝形象。

系统不依赖 X11 窗口行为；GIF 解码与绘制都在现有 Pygame/SDL 的 native Wayland 主线程中执行。

## 组件边界

- 场景目录和协议解析位于中央服务可测试模块：负责 LLM 提示片段、合法编号、重复输入继承和天气覆盖。
- `XingbaoApp` 在 KWS、LLM 回合完成、会话结束处发出显式 UI 场景命令；不把 UI 渲染逻辑置入语音线程。
- `BoardUIClient` 与 8765 NDJSON 协议增加受限的 `xingbao_scene` 载荷。
- `tools/board_phase1_ui.py` 将该载荷排入 UI 线程；`DesktopLauncher` 管理 GIF 解码缓存、帧计时、夜间计时和绘制。
- 视觉事件入口在 `main.py`：会话活跃时直接丢弃情绪事件；闲置时把已确认情绪映射为指定场景命令。

## 错误处理

- 仅接受 `0..24` 的整数场景编号；其它输入记录诊断并回退。
- GIF 缺失或单帧无法加载时不终止 UI，保留默认图像并写入诊断日志。
- UI 桥不可用时，语音与会话继续运行；场景命令仅作 best-effort。
- LLM 标记清理必须发生在文本送入 TTS/字幕之前。

## 验证

- 单元测试：LLM 场景标记解析、无效回退、同输入继承、下雨/下雪选择及 24 编号目录。
- 单元测试：动画状态优先级（KWS、对话、视觉情绪、夜间 10 分钟恢复）。
- UI 单元测试：对话锁期间情绪请求不改动场景。
- 集成验证：运行中的 Wayland 8765 UI 桥接收场景命令、确认 GIF 资源可加载、KWS 与会话结束事件不使服务退出。
