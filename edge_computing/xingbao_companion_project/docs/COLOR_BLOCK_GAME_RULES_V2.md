# 星宝色块牌阵玩法 V2

## 设计目标

玩法要让孩子愿意反复玩，而不是只看一次漂亮界面。核心体验是：拿起真实方块、通过触控或语音做出选择、看见星光变化、听到星宝回应，然后在简单策略里获得成就感。

适合年龄以 5 到 9 岁为第一目标。每局 4 到 7 分钟，三回合两胜，但最终反馈强调“点亮星阵”和“发现故事”，不强调打败孩子。

## 玩家动词

- 拿起：选择一个真实颜色方块。
- 摆放：把方块放到桌面星光区或守护区。
- 说话：用语音告诉星宝选择。
- 点触：用触控选择颜色、确认战线、改选、拖拽放置或查看说明。
- 判断：继续出块还是停手。
- 观察：看哪条线更弱、哪种颜色会连携。

## 回合流程

每回合包含四步：

1. 星宝提示当前目标，例如“这一回合我们要让两条星线都亮起来”。
2. 孩子行动：拿实体方块，选择颜色和战线。
3. 星宝行动：星宝根据局势选择一块，用语音、表情、状态动画和光效反馈。
4. 双方都停手或方块用完后结算。

一局最多三回合。先赢两回合的一方获胜；如果打平，进入“星阵共鸣”结算，按孩子本局最常使用的颜色给一个称号。

## 基础颜色

红色：勇气

- 基础效果：目标战线 +4。
- 儿童提示：“红色会让一条线马上变亮。”
- 适合在落后时使用。

蓝色：守护

- 基础效果：目标战线 +3，并让这条线进入“稳定”状态。
- 稳定状态：本回合下一次星宝得分后，如果孩子落后，孩子该线额外 +1。
- 儿童提示：“蓝色会保护这条线，不容易落后太多。”

黄色：灵感

- 基础效果：目标战线 +2，并给下一次孩子出块 +2。
- 儿童提示：“黄色这次不算最高，但会帮下一块变强。”
- 用来教学“提前计划”。

绿色：修复

- 基础效果：目标战线 +2，孩子当前较弱战线再 +2。
- 儿童提示：“绿色会照顾比较暗的那条线。”
- 用来教学“平衡”。

紫色：惊喜

- 基础效果：触发一个温和星象事件。
- 事件只做正向或轻度变化，不惩罚孩子。
- 儿童提示：“紫色会发生一点小魔法。”

## 连携规则

连携只检查孩子最近两次出块，避免记忆负担过重。

红 + 黄：勇气灵感

- 本次出块额外 +2。
- 星宝台词：“你先想到了办法，再勇敢点亮它。”

蓝 + 绿：守护修复

- 两条线中较弱的一条额外 +2。
- 星宝台词：“这是一种很稳的搭配。”

黄 + 紫：星谜灵感

- 触发一个故事选择，孩子从两个图标里选一个，得到 +1 到 +3 的温和奖励。
- 星宝台词：“灵感打开了一扇小星门。”

红 + 蓝：平衡之心

- 如果两条线分差不超过 2，孩子侧总分 +2。
- 星宝台词：“勇气和守护一起出现，很适合保护星阵。”

绿 + 紫：生命星尘

- 复活一个已经用过的颜色，孩子可在本回合再次使用一次。
- 只允许每回合触发一次。

## 星象事件

紫色和部分故事节点会触发星象事件：

- 流星雨：较弱战线 +2。
- 星尘回响：上一块颜色的效果再触发一半，向上取整。
- 小星门：孩子选择“稳一点”或“冒险一点”。稳一点 +2；冒险一点随机 +1 到 +4。
- 守护回声：如果孩子已经停手，星宝不能用红色追太多，只能温和补线。

所有事件都要可解释，不能让孩子觉得“系统偷偷改规则”。

## 停手策略

停手不只是结束操作，而是一个有意义的选择。

- 孩子领先时停手：获得“守住星光”提示，星宝更可能也停手。
- 孩子落后但还有黄色或紫色时：星宝先建议“还可以试一次”。
- 孩子连续犹豫超过 20 秒：星宝给两个选择按钮，“出一块”或“停手看看”。
- 点错或说错不扣分，只让星宝摇头并重新提示。

## 星宝 AI

星宝不是强力对手，而是陪玩伙伴。

普通难度：

- 落后时优先补弱线。
- 领先 5 分以上更容易停手。
- 不连续两次使用最高收益组合。
- 孩子明显失误时优先给提示，而不是扩大领先。

轻松难度：

- 星宝更常停手。
- 星宝优先打出教学性颜色，例如蓝色、绿色。
- 孩子落后时触发更多鼓励台词。

挑战难度：

- 星宝会使用简单连携。
- 但仍不使用不可解释的隐藏规则。

## 触控交互

屏幕已升级为触控屏。第一版应把触控作为正式主输入之一，与语音并列，而不是只在语音失败时兜底。

操作方式：

- 点颜色，再点左上或右下五格。
- 或把底部颜色小块拖到目标格。
- 点击空格时，对应真实摆放区域发光，提示孩子把实体方块放过去。
- 长按颜色显示一句效果说明。
- 点击星宝头像可以请求提示。
- 点击“停手”需要二次轻确认，避免误触。
- 语音识别出颜色或战线后，屏幕要显示可触控修正入口。
- 触控选中颜色后，星宝可以用语音追问“放到星光线还是守护线？”。

儿童友好要求：

- 关键按钮和格子建议不小于 72 px，最低不小于 64 px。
- 错误提示不使用红色警告大叉，使用星宝轻声纠正。
- 语音栏永远给例句：“红色放星光线 / 我要停手”。
- 重要状态同时用颜色、文字、星宝表情和状态动画表达，不能只靠颜色区分。
- 避免把小字说明放在必须点击的区域里，儿童应能通过大图标、大色块和短语完成操作。

## 实物方块互动

第一版不做摄像头识别，但要让实体动作有意义。

桌面建议贴两个半透明区域：

- 左侧近孩子区域：星光线放置区。
- 右侧或远侧区域：守护线放置区。

屏幕流程：

1. 孩子拿起方块。
2. 屏幕对应颜色轻亮。
3. 孩子说“红色放星光线”或触控选择。
4. 星宝说“请把红色放到星光线的小星格上”。
5. 孩子放下真实方块。
6. 屏幕槽位亮起，星宝点头动画和确认音效同步出现。

后续如果加入摄像头或传感器，只替换输入确认层，不改核心规则。

## 奖励与留存

每局结束给一个非敏感、即时的成就：

- 勇气星：红色使用得好。
- 守护星：蓝色或绿色帮助平衡。
- 灵感星：黄色连携触发。
- 惊喜星：紫色故事选择。
- 平衡星：两条线差距很小。

可记录的长期偏好仅限非敏感信息，例如“喜欢绿色方块”“偏好轻松难度”。不记录学校、住址、电话、精确位置等敏感信息。

## 第一批需要实现的玩法改动

1. 增加连携检测：只看孩子最近两次出块。
2. 增加轻松、普通、挑战三种星宝策略。
3. 增加“长时间犹豫提示”状态，由 UI 层计时触发。
4. 增加触控点选、拖拽输入、长按说明和二次确认。
5. 增加每局结束称号。
6. 紫色事件改为可解释事件列表，不使用完全不可控随机。

## 验收场景

- 孩子能不用键盘，只靠触控完成一局，也能用语音和触控混合完成一局。
- 孩子能理解每个颜色的一句话效果。
- 孩子至少在第二局开始主动尝试一次连携。
- 孩子说错战线或颜色时，星宝能温和纠正。
- 星宝赢、孩子赢、平局都能得到正向反馈。
- 没有机械臂或串口时仍可完整试玩。
