# 星宝产品主线方向

## 新定位

本项目聚焦学龄前儿童主动陪伴、成长支持与认知启蒙教育，依托 SC171V3 核心技术，打造一款智能儿童早教陪伴桌。产品以“星宝”为儿童友好的陪伴角色，通过语音、触控桌面屏视觉、实体桌面操作、多模态感知和简单的机械臂表意反馈，构建沉浸式桌面互动体验。

屏幕已升级为触控屏。触控应作为第一优先级输入之一，与语音共同构成核心交互闭环，而不是仅作为语音失败时的补充方案。

机械臂并入当前主线，但只作为语音和屏幕输出的辅助物理表达工具。它只执行点头、摇头、挥手、鼓励和保持静止等经过白名单约束的简单动作，不承担复杂编舞或任意时序动作。星宝的核心反馈仍由对话、屏幕表情、角色动画、语音播报、光效、区域高亮、触控提示和教育内容节奏共同完成。

## 核心价值

- 寓教于乐：让孩子在动手操作、趣味探索和真实桌面场景中学习。
- 认知启蒙：围绕颜色、数量、空间、规则、语言表达和基础逻辑训练组织玩法。
- 规则意识：用温和反馈、可解释规则和重复练习帮助孩子理解轮流、等待、选择和结果。
- 情绪引导：通过星宝语音、表情和鼓励话术支持挫折恢复、表达感受和建立信心。
- 主动陪伴：在合适的时机主动发起轻量互动、承接情绪和兴趣，并允许孩子随时拒绝或结束。
- 自适应互动：根据孩子的语音、操作节奏、近期偏好和游戏表现调整提示难度。
- 健康守护：加入用眼距离、连续使用时长、休息提醒和柔和视觉反馈，避免过度刺激。

## 主线能力

1. 语音闭环：唤醒、听取、ASR、LLM、TTS、连续对话和实时事件监控。
2. 触控闭环：孩子可以通过点触、拖拽、长按说明、二次确认和区域选择完成关键操作。
3. 桌面视觉交互：星宝角色状态、桌面游戏画面、区域高亮、光效和可读的儿童提示。
4. 实物桌面玩法：保留真实色块、卡片或教具摆放的动手体验，第一阶段不依赖摄像头识别。
5. 多模态感知：后续接入摄像头、传感器或桌面输入时，只替换输入确认层，不改核心规则。
6. 安全记忆：只保存兴趣、喜欢的游戏、沟通风格、近期情绪和非敏感偏好。
7. 教育内容编排：把互动游戏、故事、问答和训练目标组织成可验收的学习单元。
8. 机械臂辅助表达：只接收高层白名单动作，与语音和屏幕反馈同步，并具备限频、超时和安全回退。

## 主线边界

- 复杂机械臂编舞和任意时序动作。
- 由 LLM 生成舵机角度、PWM、GPIO、串口或原始硬件命令。
- 把 LLM 输出直接连接到任何硬件执行层。
- 存储儿童住址、电话、学校、班级、精确位置或家长联系方式。

现有 `serial_bridge` 和低层硬件代码只能作为隔离的硬件适配层。业务逻辑与 LLM 只能调用经过白名单和清洗的高层 `arm_action` 接口。

## 下一阶段路线

1. 固化 `--wake-chat` 作为语音主验收链路，降低真实设备调试成本。
2. 将色块桌面游戏从单 HTML 原型拆分为资产驱动的触控桌面视觉交互界面。
3. 建立触控优先的组件规范：大触点、防误触、拖拽预览、长按解释、儿童手指可操作。
4. 统一屏幕角色动画、光效、语音提示和简单机械臂动作的协同反馈协议。
5. 建立早教互动单元结构：目标、输入、规则、反馈、复盘和可记录偏好。
6. 增加儿童健康守护策略：时长提醒、亮度/动效约束、休息话术。
7. 为后续多模态感知保留输入适配层，但第一阶段不强依赖摄像头或传感器。
8. 建立主动陪伴机会生成、打扰控制、每日主题和效果验收指标。
