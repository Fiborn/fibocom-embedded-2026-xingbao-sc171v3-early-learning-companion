# 星宝记忆与表达联动规则 V1

## 1. 目标

星宝的记忆不是数据库堆积，而是“越来越懂孩子”的证据。记忆必须服务陪伴表达：让星宝下次能自然接上孩子的兴趣、表达方式和成长进步，同时不存储敏感信息、不强化负面标签。

## 2. 记忆分类

| 类型 | 保存时长 | 示例 | 表达使用方式 |
| --- | --- | --- | --- |
| `interest` | 长期 | 喜欢三角龙、积木、红色 | 开场接续、推荐内容 |
| `game_preference` | 中长期 | 喜欢情绪星球、颜色任务 | 推荐玩法 |
| `communication_style` | 中长期 | 喜欢二选一、说话慢 | 调整追问方式 |
| `learning_preference` | 中长期 | 喜欢图片提示、喜欢先看示例 | 调整讲解方式 |
| `recent_mood` | 短期 | 今天有点难过 | 当天安慰，不长期标签化 |
| `growth_note` | 中长期 | 今天能说出“我有点着急” | 成长记录和正向鼓励 |

## 3. 禁止记忆

不得保存：

- 家庭住址。
- 电话。
- 学校。
- 班级。
- 精确位置。
- 家长联系方式。
- 原始照片、视频、录音。
- 人脸身份数据。
- 具体同学/老师真实姓名。
- 对孩子人格的负面标签。

## 4. 写入条件

记忆写入需要满足：

1. 内容非敏感。
2. 与陪伴成长有关。
3. 有明确证据。
4. 不会造成负面标签。
5. 长期记忆尽量来自孩子主动表达或多次出现。

示例：

```json
{
  "memory_kind": "interest",
  "content": "孩子喜欢三角龙。",
  "ttl": "long_term",
  "evidence": "孩子主动说：我喜欢三角龙。"
}
```

## 5. 表达调用规则

### 5.1 开场调用

可调用：

- 兴趣。
- 喜欢的玩法。
- 正向成长记录。

示例：

```text
我还记得你喜欢三角龙。今天想听一个三角龙的小秘密，还是先玩一个小任务？
```

### 5.2 表达引导调用

可调用：

- 沟通风格。
- 学习偏好。

示例：

```text
我们还是用两个选项慢慢选，好不好？
```

### 5.3 情绪陪伴调用

只能短期、温和使用 `recent_mood`，不能长期强化。

推荐：

```text
刚刚你说有点难过，星宝还记得。现在有没有好一点？
```

避免：

```text
你总是很难过。
你就是不开心的小朋友。
```

### 5.4 成长记录调用

成长记录用于鼓励具体行为。

示例：

```text
上次你能把“我有点着急”说出来，今天我们也可以慢慢说。
```

## 6. 记忆到期规则

建议：

| 类型 | 默认 TTL |
| --- | --- |
| `interest` | 长期，直到被更新 |
| `game_preference` | 30 到 90 天 |
| `communication_style` | 30 到 90 天 |
| `learning_preference` | 30 到 90 天 |
| `recent_mood` | 当天到 7 天 |
| `growth_note` | 30 到 180 天 |

## 7. 成长记录模板

成长记录应具体、温和、非评判。

模板：

```text
今天的成长星星：
- 你愿意把感觉说出来。
- 你在小游戏里尝试了新的办法。
- 你能在提示后继续完成任务。
```

避免：

```text
今天表现优秀，超过其他小朋友。
今天注意力不够好。
今天情绪控制不好。
```

## 8. 记忆写入示例

### 兴趣

```json
{
  "memory_kind": "interest",
  "content": "孩子喜欢三角龙。",
  "ttl": "long_term",
  "sensitivity": "non_sensitive"
}
```

### 表达方式

```json
{
  "memory_kind": "communication_style",
  "content": "孩子在表达情绪时更适合二选一提示。",
  "ttl": "medium_term",
  "sensitivity": "non_sensitive"
}
```

### 成长记录

```json
{
  "memory_kind": "growth_note",
  "content": "孩子今天能说出“我有点着急”。",
  "ttl": "medium_term",
  "sensitivity": "non_sensitive"
}
```

## 9. 验收标准

记忆与表达联动合格时，应满足：

1. 星宝能自然表现“我记得你”。
2. 星宝不会暴露或存储敏感信息。
3. 星宝不会给孩子贴负面标签。
4. 星宝能把成长记录用于正向鼓励。
5. 记忆调用不会显得突兀或监控感过强。
