# 星宝硬件关系图生成提示词

## 主提示词

请设计一张 **16:9 横版、全国大学生嵌入式系统类比赛汇报级别**的中文硬件关系图，主题为：

> 星宝智能儿童早教陪伴桌——硬件设计

整体版式仿照专业嵌入式系统答辩 PPT：白色背景，左侧约 62% 为硬件关系总图，右侧约 38% 为“核心部件及作用”的编号说明，中间使用浅灰色竖线分隔。视觉风格简洁、克制、工程化、可信，不使用卡通贴纸，不使用炫彩渐变，不制作成营销海报。

### 左侧硬件关系总图

以“SC171 V3 核心计算平台”为中心节点，节点副标题为：

> 交互调度｜本地计算｜多模态融合｜网络通信

围绕核心板布置以下硬件模块，并清晰标注箭头方向、接口和作用：

1. 左上：USB 麦克风
   - 标注“语音采集、唤醒、插话”；
   - 指向 SC171 V3；
   - 连线标签为“USB 音频输入＋供电”。

2. 左中：USB 摄像头（扩展）
   - 标注“距离检测、桌面感知”；
   - 使用绿色虚线指向 SC171 V3；
   - 连线标签为“USB 视频输入＋供电”。

3. 左下：儿童与实体教具
   - 标注“说话、触摸、摆放色块/卡片”；
   - 分别与麦克风、摄像头和触控屏建立关系；
   - 表现儿童是交互闭环的起点与终点。

4. 右上：22.5 英寸触控屏
   - 标注“角色、内容、游戏、点击、拖拽、选择”；
   - SC171 V3 指向触控屏的箭头标注“显示信号”；
   - 触控屏返回 SC171 V3 的箭头标注“触控数据回传”；
   - 必须体现触控屏既是输入设备也是输出设备。

5. 右下：声卡/功放/扬声器
   - 标注“回复、提示音、鼓励语音”；
   - SC171 V3 指向该模块；
   - 连线标签为“音频输出”；
   - 从扬声器到儿童增加“语音反馈”箭头。

6. 上方：云端智能服务
   - 标注“ASR、大模型服务、TTS”；
   - 与 SC171 V3 使用双向箭头；
   - 连线标签为“Wi-Fi/LAN 双向通信”。

7. 下方：安全电源适配器/直流供电分配
   - 连接一条红色直流供电母线；
   - 分别向 SC171 V3、22.5 英寸触控屏、声卡/功放/扬声器供电；
   - 不填写未经确认的 5V、12V 或具体功率。

8. 使用灰色虚线圆角外框包围麦克风、摄像头、核心板、触控屏、音频模块和实体教具区；
   - 外框名称为“纸箱桌体”；
   - 标注“固定承载、空间分区、线缆整理”；
   - 纸箱桌体只表示结构关系，不使用数据箭头。

9. 增加一条从扬声器指向麦克风的橙色点状弧线；
   - 标注“声学回声/串音耦合”；
   - 表现整机音频设计需要处理的负向关系。

### 右侧核心部件及作用

使用 1—6 的蓝色圆形编号，配合简洁的两行说明：

1. SC171 V3 核心计算平台：统一处理语音、触控、视觉与小游戏事件，并完成本地计算、交互调度和网络通信。
2. 22.5 英寸触控屏：既输出星宝形象、学习内容和游戏画面，也回传点击、拖拽、选择等触控操作。
3. 语音交互模块：USB 麦克风采集儿童语音，声卡和扬声器播放回复，形成“听取—理解—回应”闭环。
4. 视觉感知扩展模块：摄像头用于距离检测、健康提醒和后续桌面实体教具识别，不作为基础交互的强制依赖。
5. 供电与网络模块：电源系统向核心板、屏幕和音频设备分支供电；Wi-Fi/LAN 提供云端智能服务连接。
6. 纸箱桌体原型结构：完成硬件固定、线缆整理和屏幕区/教具区划分，用于验证儿童桌面交互形态。

### 视觉与制图规范

- 主色：深蓝色和科技蓝；
- 数据线：蓝色实线；
- 音频线：紫色实线；
- 视觉扩展：绿色虚线；
- 供电线：红色粗实线；
- 结构关系：灰色虚线；
- 干扰关系：橙色点线；
- 所有连线采用横平竖直的正交路径，必要时使用总线汇聚；
- 每条线都带有清晰、准确、可读的中文标签；
- 模块使用统一圆角矩形，中央核心板视觉权重最高；
- 保持充足留白，避免线条遮挡文字；
- 标题为“1. 硬件设计”；
- 图例说明实线、虚线、供电、结构和扩展能力的含义；
- 输出高分辨率、文字清晰、适合直接放入答辩 PPT。

## 负面提示词

不要机械臂，不要舵机，不要 STM32，不要 GPIO/PWM 控制，不要光伏板，不要高压电源，不要清洁机构，不要机器人底盘，不要太阳能系统，不要工业厂房背景，不要儿童真实人脸照片，不要复杂 3D 渲染，不要赛博朋克，不要发光霓虹，不要卡通贴纸，不要无意义的数据曲线，不要虚构传感器，不要虚构接口电压，不要让线条穿过文字，不要使用错误中文，不要将扩展摄像头画成已经完全落地的必备模块。

## 输出要求

- 画布比例：16:9；
- 推荐分辨率：3840 × 2160；
- 中文字体：思源黑体、阿里巴巴普惠体或同类现代无衬线字体；
- 输出一份完整总图，并保留可编辑的矢量图层；
- 如果工具支持 SVG、PDF 或 PPTX，优先输出矢量格式；
- 所有接口名称、电压和设备型号必须以实物确认结果为准。
