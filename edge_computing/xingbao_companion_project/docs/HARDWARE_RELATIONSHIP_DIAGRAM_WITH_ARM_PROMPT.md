# 星宝硬件关系图生成提示词（机械臂补充版）

## 主提示词

请生成一张 16:9 横版硬件设计关系图，风格参考嵌入式系统比赛答辩 PPT，白色背景、黑灰线框、工程化排版、信息清晰可信。图的主题是：

```text
星宝智能儿童早教陪伴桌——硬件设计关系图（含机械臂实体反馈模块）
```

整体版式分为左右两部分：

- 左侧约 62%：硬件关系总图，展示各硬件模块之间的控制、数据、音频、视觉、供电、结构和动作反馈关系。
- 右侧约 38%：核心部件及作用说明，使用 1-7 编号列表。

左侧关系图以“SC171 V3 核心计算平台”为中心节点，节点副标题为：

```text
交互调度 · 本地计算 · 多模态融合 · 网络通信
```

围绕中心节点绘制以下硬件模块：

1. 顶部：云端智能服务  
   副标题：ASR · LLM · TTS  
   与 SC171 V3 之间使用双向箭头，标注：Wi-Fi / LAN 双向通信。

2. 左上：USB 麦克风  
   副标题：语音采集 · 唤醒 · 插话  
   指向 SC171 V3，箭头标注：USB 音频输入 + 供电。

3. 左中：USB 摄像头（扩展）  
   副标题：距离检测 · 桌面感知  
   使用虚线箭头指向 SC171 V3，标注：USB 视频输入 + 供电。视觉模块如果未实机接入，必须画成虚线扩展能力。

4. 左下：儿童与实体教具  
   副标题：说话 · 触摸 · 摆放色块/卡片  
   与麦克风、摄像头、触控屏、扬声器、机械臂形成交互关系。

5. 右上：22.5 英寸触控屏  
   副标题：角色 · 内容 · 游戏 · 点击 · 拖拽 · 选择  
   SC171 V3 指向触控屏，标注：显示信号；触控屏返回 SC171 V3，标注：触控数据回传。

6. 右中：声卡 / 功放 / 扬声器  
   副标题：回复 · 提示音 · 鼓励语音  
   SC171 V3 指向该模块，标注：音频输出；该模块向儿童与实体教具输出语音反馈。

7. 右下偏中：机械臂控制模块  
   副标题：高层动作接收 · 动作组映射 · 安全限位  
   SC171 V3 指向机械臂控制模块，箭头标注：高层动作指令 / arm_action。

8. 右下：桌面机械臂  
   副标题：点头 · 摇头 · 挥手 · 指向 · 庆祝  
   机械臂控制模块指向桌面机械臂，箭头标注：动作组执行 / 复位保护；桌面机械臂向儿童与实体教具区输出动作反馈，标注：动作反馈 / 空间指向。

9. 下方中部：总电源 / 电源分配  
   副标题：安全低压供电 · 分支供电  
   用供电线分别连接 SC171 V3、触控屏、声卡/扬声器、USB 摄像头、USB 麦克风、机械臂控制模块和桌面机械臂。机械臂的供电线请标注：独立低压供电。

10. 底部或背景虚线框：纸箱桌体与实体教具区  
    副标题：固定 · 承载 · 分区 · 走线 · 形态验证  
    用虚线结构框包围屏幕、教具区、机械臂和主要交互硬件，表示纸箱桌体承担固定承载、空间分区、线缆整理和桌面原型验证。桌面机械臂与纸箱桌体之间标注：固定 / 承载 / 走线。

请用不同线型或颜色区分：

- 数据/控制线：蓝色实线箭头。
- 音频线：紫色实线箭头。
- 视觉扩展线：绿色虚线箭头。
- 供电线：红色实线，底部可画成一条供电母线再分支。
- 机械臂动作线：橙色实线箭头。
- 结构固定线：灰色虚线。
- 声学回声/串音耦合：橙色点线，从扬声器回到麦克风，标注：声学回声/串音耦合。

右侧“核心部件及作用”请写 7 条：

1. SC171 V3 核心计算平台：统一处理语音、触控、视觉与小游戏事件，并完成本地计算、交互调度和网络通信。
2. 22.5 英寸触控屏：既输出星宝形象、学习内容和游戏画面，也回传点击、拖拽、选择等触控操作。
3. 语音交互模块：USB 麦克风采集儿童语音，声卡和扬声器播放回复，形成“听取—理解—回应”闭环。
4. 视觉感知扩展模块：摄像头用于距离检测、健康提醒和后续桌面实体教具识别，不作为基础交互的强制依赖。
5. 供电与网络模块：电源系统向核心板、屏幕、音频设备、摄像头和机械臂分支供电；Wi-Fi/LAN 提供云端智能服务连接。
6. 纸箱桌体原型结构：完成硬件固定、线缆整理、屏幕区/教具区划分和机械臂安装，用于验证儿童桌面交互形态。
7. 机械臂实体反馈模块：接收 SC171 V3 输出的高层动作指令，由机械臂控制模块完成动作组映射和安全限位，实现挥手、点头、摇头、左右指向和小幅庆祝，与语音、屏幕和触控游戏形成多模态陪伴反馈。

画面必须体现以下闭环：

```text
儿童语音/触控/桌面操作
→ SC171 V3 多模态判断
→ 语音回复 + 屏幕表情 + 机械臂动作
→ 儿童获得反馈并继续操作
```

机械臂部分必须体现以下关系：

```text
SC171 V3 → 机械臂控制模块：高层动作指令
机械臂控制模块 → 桌面机械臂：动作组执行与安全限位
总电源/电源分配 → 机械臂控制模块/桌面机械臂：独立低压供电
纸箱桌体与实体教具区 → 桌面机械臂：固定、承载、走线
桌面机械臂 → 儿童/桌面交互区：挥手、点头、摇头、指向、庆祝
```

整体风格要求：

- 关系图像专业硬件架构图，不要做成卡通海报。
- 中文字体清晰，优先使用黑体/思源黑体/微软雅黑。
- 节点文字不要拥挤，线条尽量少交叉。
- 左侧关系图要清楚，右侧说明文字要像比赛汇报页面。
- 输出 3840×2160 或矢量 SVG/PDF 质量。

## 负面提示词

不要 STM32，不要光伏板，不要高压电源，不要清洁机构，不要机器人底盘，不要工业厂房背景，不要儿童真实人脸照片，不要复杂 3D 渲染，不要赛博朋克风格，不要过度卡通贴纸，不要凌乱线条，不要虚构芯片型号，不要写具体电压电流数值，除非已经确认实物参数。

不要把 SC171 V3 画成直接输出舵机角度、PWM、GPIO 或原始串口命令。机械臂必须画成：

```text
SC171 V3 输出高层动作指令
→ 机械臂控制模块完成动作组映射和安全限位
→ 桌面机械臂执行实体动作
```
