星宝切片资产包 v3

包含：
- energy_orbs: 单独切出的红/黄/蓝/绿/紫/橙能量体（透明 PNG）
- icon_set: 12 个主功能图标（透明 PNG）
- ui_controls: 按钮、状态 chip、进度条、返回箭头、分页点、小标签等
- state_cards: 色彩能量舱横向选项卡的 5 种状态参考图
- panels: 伙伴侧栏、顶部任务栏、反馈栏、任务卡框架、顶部状态条、能量条
- backgrounds: 舞台背景图

说明：
1. 大多数小元素已做透明抠图，适合直接插入 pygame / Web / 设计工具。
2. panels 和 state_cards 保留原有深色面板底，适合整体作为底图。
3. 详细文件索引见 manifest.json。
